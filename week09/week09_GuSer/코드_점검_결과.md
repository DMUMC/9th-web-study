## 🔧 수정된 오류

### 1. TypeScript 타입 오류 (LPListPage.tsx)
**문제:**
- `useInfiniteQuery`의 타입 추론 실패로 `page`가 `never` 타입으로 추론됨
- `Property 'filter' does not exist on type 'never'` 오류

**해결:**
- `LP` 타입을 명시적으로 import하여 사용
- `flatMap` 내부에서 타입을 명시적으로 지정

```typescript
import { getLPs, type LPListResponse, type LP } from '../apis/lp';

const lps = data?.pages.flatMap((page: LPListResponse) => {
  // ...
  return Array.isArray(pageLps) ? pageLps.filter((lp: LP) => lp && lp.id) : [];
}) ?? [];

// map에서도 타입 명시
{lps.map((lp: LP) => {
  // ...
})}
```
